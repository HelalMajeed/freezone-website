# قوالب سمات الأقسام

قوالب جاهزة لتسريع إعداد `CategoryAttribute` عند إنشاء أقسام جديدة.

## القوالب المتوفرة

| المعرّف | الاسم | الاستخدام |
|---------|--------|-----------|
| `smartphone` | هواتف ذكية | تخزين، RAM، شبكة، لون |
| `laptop` | حواسيب محمولة | معالج، RAM، SSD، GPU |
| `tv` | تلفزيونات | مقاس، دقة، لوحة |
| `accessory` | إكسسوارات | نوع، توافق |

## API

- `GET /api/admin/category-templates` — قائمة القوالب
- `POST /api/admin/categories/:id/apply-template` — body: `{ "templateId": "smartphone" }`

التطبيق يستخدم **upsert** — لا يحذف السمات الموجودة، يضيف/يحدّث مفاتيح القالب فقط.

## من الواجهة

لوحة **الأقسام** → قائمة ⋮ للقسم → **تطبيق قالب سمات**.
